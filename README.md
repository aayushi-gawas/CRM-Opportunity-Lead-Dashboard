# CRM Opportunity & Lead Analytics Dashboard

An interactive **CRM Analytics Dashboard** developed using **Power BI, Excel, Tableau, and SQL** to analyze leads, opportunities, sales performance, conversion trends, and revenue.

## 📌 Project Overview

This project focuses on analyzing CRM data to provide business insights into:

- Lead generation and conversion
- Lead status and lead sources
- Opportunity pipeline
- Sales performance
- Revenue generated from won opportunities
- Customer and industry trends
- Monthly lead and opportunity trends

The project includes data cleaning, transformation, SQL analysis, KPI development, and interactive dashboard creation.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development, DAX, Power Query
- **Excel** – Data cleaning, analysis, Pivot Tables and dashboard preparation
- **SQL** – Data querying, joins, aggregations and SQL Views
- **Tableau** – Data visualization and interactive reporting

## 🔍 Data Analysis & Transformation

The project involved:

- Data cleaning and validation
- Handling missing and inconsistent values
- Data type transformation
- Creating calculated columns and measures
- Building relationships between CRM tables
- Creating SQL joins and aggregations
- Developing SQL Views for dashboard reporting
- Creating DAX measures in Power BI
- Creating interactive filters and slicers

## 📈 Key Insights

The dashboards help analyze:

- Lead conversion performance
- Lead distribution across sources and industries
- Monthly lead generation trends
- Opportunity pipeline by stage
- Revenue generated from won opportunities
- Industry-wise opportunity performance
- Top-performing accounts
- Sales conversion and win-rate trends
